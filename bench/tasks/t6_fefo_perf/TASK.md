# 과제: 재고 할당 함수 성능 개선

`allocator.py` 의 `allocate(orders, lots)` 는 주문을 재고 로트에 배정하는 함수입니다. 결과는 맞지만 너무 느려서, 주문 20만 건과 로트 5만 개 규모에서 몇 분이 걸립니다. 같은 입력에 대해 **완전히 같은 결과**를 내면서 이 규모를 2초 안에 처리하도록 고쳐 주세요.

- 함수 이름, 인자, 반환 형식은 그대로 유지합니다.
- 입력 리스트와 그 안의 객체를 변경하면 안 됩니다(호출한 쪽이 다시 씀).
- 기존 테스트 `test_allocator.py` 는 그대로 통과해야 합니다.
- 할당 규칙은 현재 코드의 docstring 과 동작이 기준입니다. 코드를 읽고 규칙을 정확히 파악한 뒤 바꿔 주세요.

성능을 확인하는 측정과 동일성 검증 테스트도 추가해 주세요.
