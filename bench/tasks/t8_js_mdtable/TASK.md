# 과제: 마크다운 표 포매터 (JavaScript)

Node.js(v22) 용 CommonJS 모듈 `mdtable.js` 를 만들어 주세요. 외부 패키지는 쓰지 않습니다.

```js
const { formatTable } = require('./mdtable');
formatTable(rows, { align } = {}) // -> string
```

- `rows` 는 2차원 배열이고 첫 행이 헤더입니다. 셀 값은 문자열, 숫자, `null`/`undefined`(빈 칸) 중 하나입니다. 숫자는 `String(n)` 으로 변환합니다.
- 행마다 칸 수가 다르면 가장 긴 행에 맞춰 빈 칸을 채웁니다.
- `align` 은 열마다 `'left' | 'center' | 'right'` 를 담은 배열(생략 시 모두 left). 구분선은 left `:---`, center `:---:`, right `---:` 이며 대시 개수는 열 너비에 맞춥니다(콜론 포함 길이가 열 너비와 같게, 단 최소 3칸 너비).
- 모든 행은 `| a | b |` 처럼 양 끝에 `|` 가 있고 셀 앞뒤로 공백 한 칸입니다. 각 셀은 정렬 방향에 맞춰 공백으로 열 너비까지 채웁니다. center 에서 남는 한 칸은 오른쪽에 둡니다.
- 열 너비는 그 열 셀들의 **표시 폭** 최댓값(최소 3)입니다. 표시 폭은 한글·한자·일본어 가나·전각 문자 등 동아시아 전각 문자를 2, 나머지를 1로 셉니다(이모지는 고려하지 않아도 됩니다).
- 셀 안의 `|` 는 `\|` 로, 줄바꿈(`\n`, `\r\n`)은 `<br>` 로 바꿉니다. 폭 계산은 바꾼 뒤 문자열 기준입니다.
- 결과 문자열은 줄을 `\n` 으로 잇고 끝에 줄바꿈이 없습니다.
- `rows` 가 배열이 아니거나 비어 있으면 `TypeError`.

`node --test` 로 실행되는 테스트도 함께 작성해 주세요.
